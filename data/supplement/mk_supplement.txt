# Curated additions to the upstream Hunspell wordlist.
#
# The upstream dictionary (OSSM / Taras Bendik) is a flat list of surface forms
# with no affix rules, so it has systematic holes. This file fills the ones that
# are *categorical* — whole classes of correct Macedonian it never covered.
#
# It deliberately does NOT collect individual words observed missing in some
# corpus. That way lies overfitting to whatever text happened to be sampled.
# General vocabulary coverage is a morphology problem, to be solved by deriving
# paradigms from apertium-mkd, not by hand-listing forms here.
#
# Lines starting with '#' are comments. One form per line.

# ---------------------------------------------------------------------------
# Grave-accented forms.
#
# These are correct Macedonian orthography, not decoration: the accent is the
# only thing distinguishing two different words. Written with Cyrillic
# ѐ U+0450 and ѝ U+045D — the Latin lookalikes è U+00E8 and ì U+00EC are errors
# and are caught by the homoglyph rule.
# ---------------------------------------------------------------------------
